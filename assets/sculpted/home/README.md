# Small-adult home guard

`author.py::woven_home` owns the editable source and runtime export. The front
and side guard is lower for the .365-scale adults, with a real front opening
along the ladder/home-entry route. Floor, ladder, rear hood and berth endpoints
are retained. This home still commissions two sheltered sleepers.

`qualification.json` records the one-time decoded comparison with the preceding
home export: all 13 floor cords, the complete ladder and complete rainhood are
identical. The wall and uprights intentionally changed. It also binds the current
GLB, Blender source and recipe hashes to the measured guard/entrance checks.
`qualify.mjs` accepts an optional preceding GLB path for that comparison; keep the
baseline comparison evidence when qualifying later intentional changes.
