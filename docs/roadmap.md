# Roadmap

## Foundation now

Story and art source ownership; strict browser stack; pure one-choice simulation;
four procedural animated chicken stand-ins; character wants/fears; remembered
social consequences; local versioned save and transfer. These establish an
integrated slice, not a campaign.

## Next meaningful slice

Choose one follow-up scene in which Mallow or Bramble acts on this evening.
Agree the player role and authority first. Prove that character memory changes
an available option or behavior. Avoid adding generic population/resources first.
Create one production chicken rig with authored emotional motion, validate it
in the existing camera, then replace stand-ins without changing simulation rules.

## Later, with explicit design

Daily routines and pecking order; neighboring coops and pacts; kinship/marriage
moves with named-character responses; hatching and generational continuity;
longer saves/migrations. Multiplayer comes after a compelling single-player
loop and an explicit authority/synchronization design. No dates or systems are
promised by this list.
